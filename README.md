# JumJum

A music player for **Windows** and **Android** that handles everyday files and high-quality lossless audio.

- Lossless and hi-res playback (FLAC, WAV, ALAC, APE, WavPack, DSD and more on Windows); bit-perfect WASAPI exclusive mode on Windows
- 10-band equalizer with live Smart EQ, and a frequency visualizer (with fullscreen)
- Time-synced karaoke lyrics: search online, import your own, or generate them on-device with AI (Whisper, 99 languages)
- Internet radio and stream links, folders, autoplay choices, drag and drop, volume control

## Download

Get the latest version from **[Releases](https://github.com/vistrae/jumjum/releases/latest)**:

| | File |
|---|---|
| Windows 10/11 (64-bit) | `JumJum-<version>.msi`: run it and follow the installer |
| Android 8.0+ | `JumJum-<version>.apk`: open it on your phone (allow installing from your browser or file manager when asked) |

## Updates

JumJum checks for new versions once a day (or **Menu > Check for updates**) and installs them for you. The update checksum is verified before anything is installed.
